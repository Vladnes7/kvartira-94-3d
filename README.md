# Квартира 94 м² — 3D-прогулка

Интерактивная 3D-модель квартиры по рабочим чертежам (обмерный план, план перегородок, план мебели, развёртки). Дизайн повторяет визуализации проекта.

- Ходьба от первого лица со столкновениями (стены, мебель, закрытые двери)
- Двери открываются кликом / тапом
- Обзор «кукольный домик» сверху, мини-план для перехода по комнатам
- День / вечер / ночь
- Панель «Отделка»: ~35 вариантов цветов и материалов по комнатам
- Полный экран (кнопка или клавиша F), на телефоне джойстик, свайп-обзор и кнопка «Бег»

## Управление
Компьютер: `W A S D` — идти, `Shift` — быстрее, мышь — осмотр, клик или `E` — дверь, `F` — полный экран.
Телефон: джойстик слева, свайп справа, тап по двери. На iPhone для полного экрана: «Поделиться» → «На экран Домой».

## Сборка
```
npm install
npm run build   # dist/index.html (сайт) и dist/Квартира-94м2.html (один офлайн-файл)
npm run dev     # исходники без сборки: http://localhost:8794
```
Стены и проёмы извлечены из векторов PDF (масштаб 1:48) — `js/plan-data.js`. Текстуры генерируются процедурно, внешних картинок нет.
